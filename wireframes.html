Nextly

A Things-style task manager for Windows, macOS and iOS. Work is organized by what you'll do Today and what comes Next, with dates kept optional.

Windows 11 · macOS 15 · iOS 18
Self-hosted sync over Tailscale
How work gets organized
Today

Your list for today. Anything still open tonight stays here tomorrow. It doesn't turn red or count as overdue.

Next

The short queue you pull from when Today is clear. You set the order by dragging. One keystroke promotes a task to Today.

Waiting on

A task that depends on other open tasks is greyed out until those are finished. Then it moves to Next on its own.

Deadline · optional

A small chip, not a way of sorting. Tasks with deadlines show up in Scheduled. Today and Next never depend on a date.

Shared across platforms

Inside a task

Subtasks

A subtask is a full task with a parent. It can have its own notes, flag and dependencies. Subtasks nest up to three levels deep. A parent shows a count like 2/5, and finishing the last subtask asks whether to finish the parent too.

Dependencies

  • Depends on: this task stays greyed out until those tasks are done.
  • Blocks: the reverse view, filled in for you.
  • Adding a link that would create a loop isn't allowed, and the editor shows why.
  • When the last blocking task is finished, this task moves to Next unless it was already in Today.

Notes, blog-style

Notes are a list of blocks stored as JSON, so the editor works the same on every platform and syncs one block at a time.

heading · paragraph · checklist · quote
image · file · email · link · divider

Files are stored under their SHA-256 hash, so each file uploads once even if several tasks use it.

Email to task

Three ways to capture email

Best

In-app Gmail picker

Google sign-in on each device with the gmail.readonly scope. The picker searches mail and saves the message ID, subject, sender and date. It never saves the email body.

Links use mail.google.com/mail/u/0/#all/<id>, which works in a browser and in the Gmail iOS app.

Fastest to build

Chrome & Safari bookmarklet

One click in Gmail reads the open email's subject and ID and opens a small "Add to Nextly" window served by your sync server. No Google sign-in needed. The script is in capture/gmail-bookmarklet.js.

iOS & macOS

Share extension

Share › Nextly from the Gmail app, Mail or Safari. Mail.app passes a message:// link, and Gmail passes a web link. Both show up as email cards in the task's notes.

Before you connect a school Gmail account Your district's Google Workspace admin may need to approve a custom app before it can request Gmail access. Notes and attachments go to your own server, not a district system, so keep student records out of them. That includes grades, IEP or 504 details, and parent emails about specific students. Basic directory information, like a name on a conference list, is the most you should store.
Sync

Docker server on your tailnet

Recommendation: run a small sync server in Docker, reachable only over Tailscale. Tailscale connects the devices but doesn't sync anything by itself, so something still has to merge changes. Syncthing copies whole files, and iOS has no official Syncthing client. A small server handles merging per record. It uses the Tailscale you already run on the host and listens only on the host's Tailscale address, so your phone can reach it anywhere without opening any ports.

How sync works

  • Each device works from its own local copy, so the apps run fully offline.
  • Every change gets a timestamp that sorts correctly even if a device's clock is slightly off. If two devices edit the same record, the newer timestamp wins.
  • Each device sends its unsent changes and gets back everything newer than the last change it saw.
  • A deleted record is kept with a "deleted" mark, so the deletion reaches every device.

Suggested client stack

Tauri 2 builds Windows, macOS and iOS apps from one React + TypeScript codebase, with local SQLite through its SQL plugin. The iOS share extension is the only part that needs native Swift.

If the Mac and iPhone apps need to feel fully native, use SwiftUI there and WinUI 3 on Windows. Both talk to the same sync API.
